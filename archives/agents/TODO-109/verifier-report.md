# TODO-109 verifier report

## 方法
- `python3 -m http.server 8199` で `player.html` を配信し、Playwright
  (chromium, `/tmp/verify064/node_modules/playwright`, v1.63.0) で実測した。
- 対象: `player.html`、`player.html?slides=user`、それぞれ 1280x800 と
  375x667。

## 変更内容
`git diff -- player.html` はヘッダー左のアイコンを `<div>` から
`<a href="index.html" title="スライド一覧へ戻る" aria-label="スライド一覧へ戻る" ...>`
に変えた 1 箇所のみ。クラスは元と同じものを維持し、`flex-shrink-0` を追加。
指示された範囲と一致している。

## 1. 遷移確認
4 通り（2 URL × 2 viewport）すべてでアイコンをクリックすると
`http://localhost:8199/index.html` に遷移した。一致。

## 2. 見た目・大きさ（getBoundingClientRect）
すべて 32x32（`width: 32, height: 32`）で一致。位置は viewport により
異なる（1280x800: x=24,y=16 / 375x667: x=12,y=10）が、これは元々の
パディング差によるもので妥当。

## 3. 横スクロール（scrollWidth / clientWidth）
4 通りすべて `scrollWidth === clientWidth`（1280 と 1280、375 と 375）。
横スクロールは出ていない。

## 4. コンソールエラー
4 通りすべて `consoleErrors: []`。追加のスペースキー確認（本文の body に
フォーカスした状態でのスペース押下）でもエラー無し。

## 5. キーボード操作（要注意の実測結果）
- 再生/一時停止ショートカット: `player.html` の keydown ハンドラ
  （1550 行目付近）は `e.target.closest('button, input, textarea, select,
  a, [contenteditable]...')` で **`a` タグを既に除外している**。実測でも
  アイコンにフォーカスした状態でスペースを押した前後で `#play-btn` の
  `title` 属性（"再生（Space）"）は変化せず、`togglePlay()` は発火しなかった。
  → 再生/一時停止ショートカットは従来どおり効く。
- **意図しない動作: ページのスクロール。** 375x667 でアイコンに `Tab` で
  フォーカスを当ててスペースを押すと、`window.scrollY` が `0` → `367` に
  変化した（実測値）。1280x800 では `scrollY` は `0` → `0` のまま変化しな
  かった（ページ全体が viewport に収まりコンテンツがスクロールできないた
  め）。
  - 原因の推定（未確認）: アイコンが `<a>` になり Tab フォーカスの対象に
    含まれるようになった。アプリの keydown ハンドラは `a` を除外して
    `return` するため `preventDefault()` を呼ばず、ブラウザ標準の
    「フォーカスされた要素上でのスペース押下＝ページを 1 画面分スクロール」
    という既定動作がそのまま働いたと見られる。以前はアイコンが `<div>`
    （フォーカス不可）だったため、この経路自体が存在しなかった。
  - **実害は未確認。** モバイル幅で Tab 操作かつスペースキーを使う利用者に
    限られる操作であり、機能的な誤動作（誤ページ遷移や再生の誤発火）では
    なく画面が下にスクロールするだけ。指示にあった「意図しない動作がない
    か」を確かめる項目として、判断は管理者に委ねる。
