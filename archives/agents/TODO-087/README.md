# TODO-087 の分担

| 担当 | 役割 |
|------|------|
| main | Pages の有効化、失敗の切り分け、`.nojekyll` の設置 |
| verifier | 公開した URL の実機確認 |

## この分担にした理由

変えたのは空ファイル 1 つ（`.nojekyll`）だけだが、**実装した本人は
「HTTP 200 が返った」で済ませてしまう**。200 はトップの HTML が取れたことしか
意味せず、`slides/*.js` が読めているか、スライドが実際に描画されるかは別。
だから確認を別の担当に分けた。

reviewer は立てていない。ファイルを足しただけで分岐や条件式は変わっておらず、
「良いか」を問う対象が無い。

## 依頼の条件

確認の手段まで指定した（Playwright / headless Chromium / 1280x800）。
書かないと静的な読み合わせ（`curl` で HTML を読むだけ）で返ってくるため。
レイアウトの測り直しと TTS は対象から外し、そのぶんスクリーンショットの
目視（不透明か、欠けていないか）は残した。
