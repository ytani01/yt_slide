# TODO-090 の分担

| 担当 | 役割 | 報告 |
|------|------|------|
| verifier | `duration` をずらした／省いたときの挙動を Playwright で実測 | [verifier-report.md](verifier-report.md) |

## この分担にした理由

コードを読めば挙動の見当は付くが、「目分量でよい」と文書に書くには
**実際に何が起きるか**を測っておく必要があった。実装の変更は無く、
確かめるのは実測だけなので、実装とレビューの担当は立てていない。

`measure.js` は計測スクリプト。測り直すときは報告ファイルに書いてある
テスト用スライドを置き直してから使う。
