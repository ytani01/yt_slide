### ケース A: 再生を始めてから、1 枚目の読み上げ中（t=3s）で消音

```
(0.0, '#1', '消音中') ... (10.0, '#1', '消音中')
(12.1, '#1', '朗読完了')
(14.1, '#2', '消音中')
```

t=12.1s でバッジが「朗読完了」に変わり、t=14.1s で `#1`→`#2` に進んだ
（duration12s＋待ち2s＝14s と符合）。**前回（修正前）は 30 秒待っても
`#1` のままだったが、今回は進んだ。**

### ケース B: 先に消音してから再生（退行確認）

```
(0.0, '#1', '消音中') ... (10.0, '#1', '消音中')
(12.0, '#1', '朗読完了')
(14.0, '#2', '消音中')
(26.1, '#2', '朗読完了')
(28.1, '#3', '消音中')
```

前回と同じ挙動（duration＋待ち秒数どおりに `#1`→`#2`→`#3`）。**退行なし。**

### ケース C: 読み終わりの待ちの最中に消音（新規）

速度 2.0x・待ち 1 秒に変更し、バッジを 100ms 間隔でポーリングして
「朗読完了」に変わった直後（t=8.29s、1 枚目の途中）に消音ボタンを押した。

```
[Case C] muted at t=8.29s (badge showed '朗読完了'; speed=2.0x, pause=1s)
(0.0, '#1', '朗読完了')
(2.0, '#2', '消音中')
```

消音ボタンを押した直後の観測（t=0.0s、消音直後の 1 回目のポーリング）で
バッジはまだ「朗読完了」、次の観測（t=2.0s、ポーリング間隔 2 秒）で
`#1`→`#2` に進んでいた。**待ち（1 秒）が延びた様子はなく、そのまま
次へ進んだ。** 以降も `#2`→`#3`（t=6→8s 付近）、`#3`→`#4`（t=14→16s 付近）
と、消音を挟んでいない区間も含めて規則的に進み続けた。

### 結論（事実のみ）

3 ケースいずれも、消音を挟んでも `duration` ＋待ち秒数で次のスライドへ
進んだ。ケース A は修正前後で挙動が変わり（進まない→進む）、ケース B は
変化なし（退行なし）。
