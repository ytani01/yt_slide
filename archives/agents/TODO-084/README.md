# TODO-084 の分担

文書・スライドと実装の食い違い 6 件と、実装の疑い 1 件（再生中に消音すると
スライドが進まない）をまとめて直した項目。

## なぜこの分担にしたか

- 項目 7 は**挙動が変わる**ので、確認（verifier）とは別にレビュー（reviewer）を
  入れた。「動くか」と「良いか」は別で、テストが通っても分岐の意味が
  変わったことは捕まえられないため
- 項目 7 は「コードを読んだ見立て」でしかなかったので、**実装の前に実測させた**。
  見立てのまま始めると、実装・確認・レビューがまとめて誤った前提の上で動く
- 項目 1〜6 は複数のファイルにまたがり、`duration` の測り直しまで要るので
  implementer に回した。`player.html` は触らせず、項目 7 と衝突させなかった
- 再現と最終確認は**同じ verifier に続けて頼んだ**。立て直すと計測の
  組み直しから始まるため。計測スクリプトは 1 本だけ作らせ、ここに残した
- reviewer を先、verifier を後に回した。並行させると、reviewer の指摘で
  実装が変わり、verifier の実測が古い差分に対するものになる
