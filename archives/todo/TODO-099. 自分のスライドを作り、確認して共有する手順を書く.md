## きっかけ

`docs/User.md` の「手順」は `player.html` が手元にある前提で始まり、
`ytslide init` は末尾の「公開」の節に埋もれていた。`ytslide update` の
位置づけも「手順」の括弧書きと「`narration` と `duration`」の節に散らばって
いて、「初期化する → スライドを書く → 増やしたら何を走らせる」という
一本の流れが無かった。

TODO-095・TODO-096 でリポジトリの外に自分のスライドを置けるようになった
ので、標準を `ytslide init` で自分のディレクトリを作る形に寄せた。
同じ内容を持つ `README.md` と `slides/user.js` もまとめて直した。

## やったこと

対象は `README.md`、`docs/User.md`、`slides/user.js` の 3 ファイル。

**流れを利用者の作業順に組み直した。** 最初の到達点を「自分の内容を 1 枚
表示し、読み上げを確認できる」に置き、その後で編集の繰り返し、一覧の更新、
時間の測定、HTTP での確認、共有を目的ごとの分岐にした。コマンドを全部
順番に実行することを完成条件にしていない。

- `docs/User.md`: 冒頭に「### 1. 自分の作業場所を用意する」「### 2. 最初の
  1 枚を書いて再生する」「### 3. 編集して確かめる」を置き、一覧・測定・HTTP・
  別ディレクトリからの実行を任意の分岐にした。プレイヤーの操作ガイド、
  チャプター一覧の検索、声の選択、音が出ないときは後半へ移した。
  末尾にあった「リポジトリの外に自分のスライドを置く」は冒頭へ統合した
- `README.md`: インストール → 作業場所 → 最小例 1 枚 → 再生の流れにした。
  `uv` の公式手順へのリンクと Python の条件を補い、サブコマンド表に
  使う場面を添えた
- `slides/user.js`: 「手順1〜4」の 4 枚を「準備する」「書いて確かめる」
  「一覧・仕上げ・共有」の 3 枚にまとめ、必須と任意を分けた。
  16 枚になったので総枚数の表示も直した
- 例の名前を `sample` に統一した。最小例は `README.md` と `docs/User.md` で
  同じものにした
- `ytslide web` の説明に、LAN 内の IP アドレスの調べ方と
  `http://<LAN内IP>:8000/` の形、作業ディレクトリ全体が配信されることを足した
- ナレーションを変えた枚の `duration` を `ytslide update --slides user` で
  測り直した（3 枚目が 12 → 15。他の 15 枚は変化なし）

**引き継ぎ時に直したもの。** codex の作業がトークン制限で止まったため、
未コミットの差分を `cmd` の作業ツリーへ移してから Claude が続けた。

- `README.md` のインストール元から `@cmd` を外し、`main` を指す形に戻した
  （利用者の判断）
- `README.md` の最小例を `docs/User.md` の「最小の例」と同一にした
- `docs/User.md` の「`--text` に文章を渡すと、どのスライド一式でも測定できる」を、
  `--slides` が要る旨に書き換えた
- `slides/user.js` の `ytslide measure --text '文章'` に `--slides sample` を足した
- `slides/user.js` の 3 枚目のナレーションに `index.html` を足した
- reviewer の指摘により、最小例のコードフェンスを `js` に揃え、
  「`measure`・`index` を単独で使える」を `README.md` にも書き、
  「型の見本 19 枚」が「一覧に 19 件並ぶ」と読めた箇所を書き分けた

## 確かめたこと

`pytest` は 25 passed（動作コードは変えていない）。`node --check` と
`git diff --check` も通った。`slides/user.js` は 16 枚で、総枚数の表示と一致する。
ナレーションはすべて `TTS_MAX_CHARS` の 180 字以内（最大 118 字）。

**実測での確認**（verifier。報告は
[`archives/agents/TODO-099/verify-report.md`](../agents/TODO-099/verify-report.md)）:

- `/tmp` の空のディレクトリで `ytslide init` から始め、`docs/User.md` の
  「最小の例」をそのまま保存して `file://` で `?slides=sample` を開き、
  測定なしで本文とナレーションが読めることを確認した。編集して再読み込みすると
  表示が変わる。`?slides=` を省いたときのエラー文言も文書と一致した
- `ytslide index` の前後で一覧のリンクが増え、リンクから開けた。
  `summary`・`icon` を省いた例も警告付きで一覧に載り、説明は空欄、
  アイコンは `fa-file` になった
- `ytslide update --slides sample` で `duration` が書き戻され、一覧が再生成された
- `ytslide web` はブラウザを開かず、HTTP の URL で再生と一覧が見られた。
  公開用のファイルだけを別ディレクトリへ移しても動いた
- `player.html?slides=user` を 1280×720 と 390×844 で全 16 枚巡り、
  スクリーンショットを実際に見て、欠け・はみ出し・重なりが無いことを確認した。
  改稿した 3・4・5 枚目の本文の計算後 `font-size` は 16.492px（1280 幅）と
  17.29px（390 幅）で、下限の 0.9rem = 14.4px を下回らない
- `README.md` の手順だけでも `docs/User.md` と同じ状態に到達できた

**未確認**: 別端末からの LAN 接続（実機が 1 台のため測れない）。
`uv tool install` によるインストールの再現（下記「残ること」）。

## 分担の振り返り

- **reviewer が見つけたもの**: 最小例のコードフェンスの不一致、
  `README.md` に「`measure`・`index` を単独で使える」が無いこと（TODO の
  チェック項目に書いてあったのに落ちていた）、「型の見本 19 枚」が
  「一覧に 19 件並ぶ」と読める書き方。いずれも 3 ファイルを突き合わせないと
  出てこないもので、実装した側からは見えなかった
- **verifier が見つけたもの**: 食い違いは無かった。ただし
  「実際にそのとおりに動く」ことを測った意味は大きい。`init` が置くファイル、
  警告の文言、エラーの文言、フォントサイズの実測値が、すべて文書と一致した
- **main が見つけたもの**: `ytslide measure --text '文章'` が `init` した先で
  traceback で落ちること。これは実際にコマンドを叩いたから分かったもので、
  差分を読むだけでは出てこなかった。**実装を引き継ぐときは、書いてある
  コマンドを 1 つ実行してみるところから始めるとよい**
- **見込みとの食い違い**: 見込みは「Sonnet 5 / reviewer + verifier」だったが、
  実際には実装を codex が行い、Claude は引き継ぎ・見直し・確認だけを担当した。
  結果として「実装した本人とは別の目で見る」形になり、CLAUDE.md が
  求めている分け方に自然に沿った
- **次に同じ規模を組むなら**: main の割合が 69% と大きい。3 ファイルの差分を
  main が全部読んだためで、ここは減らせる。**差分を読んで要件と突き合わせる
  ところまで reviewer に渡し、main は指摘の採否だけを判断する**形にすれば、
  main の読み込み分が reviewer 側（単価が 1/5）へ移る。ただし
  「コマンドを実際に叩く」判断は main に残す必要がある（reviewer には
  実行させない決まりなので、落ちるコマンドは reviewer からは出てこない）

分担の理由と各担当の報告は
[`archives/agents/TODO-099/`](../agents/TODO-099/) にある。

## 残ること

- **`ytslide measure --text '文章'` が `ytslide init` した先で
  `FileNotFoundError` の traceback で落ちる。** 読みの置換表を読む
  `load_slides_rules()` が `slides/<名前>.js` を無条件に開くため。
  既定の `readme.js` は `init` した先に無い（TODO-098 と同じ形の残り）。
  文書側は `--slides <名前>` を添えて回避してある。コードの修正は別項目にする
- **`README.md` のインストール元は `main` を指しているが、`origin/main` は
  現在 `pyproject.toml` を持たない。** 書いたとおりに実行しても CLI は入らない。
  `cmd` を `main` へマージすれば解消する
